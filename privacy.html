상속한눈으로 돌아가기

개인정보 안내

시행일: 2026년 11월 19일 · 웹 초기 버전

입력한 자료는 어디에 있나요?

상속한눈 웹은 별도 회원가입 없이 사용할 수 있습니다. 처음에는 입력한 가족관계, 재산, 채무, 체크리스트가 현재 브라우저 메모리에만 있습니다. 새로고침하거나 창을 닫으면 이 자료는 사라집니다.

기기에 저장하기

사용자가 비밀번호를 설정해 저장한 경우에만 브라우저 저장 공간에 암호화한 자료를 보관합니다. 암호화는 PBKDF2-SHA256(310,000회)과 AES-GCM 256비트를 사용합니다. 비밀번호와 복호화 키는 저장하지 않습니다. 비밀번호를 잊으면 자료를 복구할 수 없습니다. 기기를 함께 사용하는 사람이 앱이 열린 동안 자료를 볼 수 있으므로 사용 후 잠금 기능을 이용하세요.

백업과 삭제

백업 파일은 사용자가 직접 내려받고 관리하는 암호화 파일입니다. 기기의 자료를 삭제해도 이미 내려받은 백업 파일은 자동으로 지워지지 않습니다. 전체 삭제는 이 브라우저의 상속한눈 저장 자료와 현재 열린 자료에 적용됩니다. 브라우저 데이터 삭제나 기기 변경에 대비해 백업을 별도로 보관하세요.

서버 전송과 외부 서비스

이 웹 버전은 입력한 개인정보를 서버로 전송하지 않으며, 분석 추적 도구·광고 SDK·외부 웹폰트를 포함하지 않습니다. 웹 호스팅 제공자는 페이지 접속 과정에서 통상적인 접속 정보를 처리할 수 있습니다. 공식 기관 링크를 직접 선택해 이동하면 해당 기관의 개인정보 처리방침이 적용됩니다.

Android 앱

Android 앱은 네이티브 Google Mobile Ads 및 UMP를 사용합니다. 광고가 활성화된 경우 해당 SDK의 별도 동의·개인정보 설정 안내가 적용되며, 개발용 Debug 빌드에는 테스트 광고를 사용합니다. 재산·가족 입력값은 광고 요청 데이터에 포함하지 않습니다. 웹과 Android 사이에는 파일 저장·인쇄 요청 및 민감 입력 중인지 여부만 제한적으로 전달하며, 암호화 백업은 사용자가 선택한 기기 위치에 저장합니다.

자료의 범위

주민등록번호, 계좌 비밀번호, 인증서 등은 입력하지 마세요. 연락처나 계좌번호 없이 관계·기관명·금액·서류 준비 상태만으로 이용할 수 있습니다. 암호화 저장은 기기 악성코드나 화면 열람까지 막아주는 기능은 아닙니다.
